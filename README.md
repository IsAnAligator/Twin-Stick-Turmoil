# Twin-Stick-Turmoil
Unity Version 6000.4.8f1

# Setup Info
Before doing anything, you should download and install [GitHub Desktop](https://github.com/apps/desktop) to make 
everything 1000% easier.	
Connect your GitHub Desktop to your GitHub account.	

Once your GitHub Desktop is setup, go to the Online GitHub repository, click the green "Code" button, and click the 
"Open with GitHub Desktop" option in the dropdown. 	
This should open your GitHub Desktop which will try to make a local copy of the main repository.
	
Once it finishes adding all the files, you open Unity Hub.	
Make sure you have Unity version 6000.4.8f1 installed, and then click "Add" -> "Add project from disk" and select 
the "Twin-Stick-Turmoil-Game" folder.	
When you open the Twin-Stick-Turmoil-Game project, Unity will fill in the remaining temporary files that aren't 
pushed to GitHub. These files will be ignored whenever you push changes.	

# Branches & Pushing
**!! The first thing you should do if you plan to make any changes to the project is make a new Branch !!**	
Making any changes in Branches makes it easy to cancel or revert any changes, and have a parallel version of any
decisions to compare. It also helps prevent any conflicts, edits being overwritten, etc etc.	
_Also, please make detailed comments of any changes you commit to branches, It will make reviewing branch merges easier_	

When you commit changes from GitHub Desktop, it won't automatically be pushed to the Online Repository. Ideally, whenever
you commit a change on your Local repository, you should also push that change to your branch in the online repository.	

When its time to merge any changes in your branch with the Main branch, then you have to do a proper Pull request, and before
a Pull request is properly merged, we have to have a discussion about any changes and manage any conflicts and things and such.
